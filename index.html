Overview

Built for simple publishing

GitHub Pages works best when the website is made of static files. This starter keeps everything direct: one HTML entry page, one stylesheet, one script file, and an assets folder for images or downloads.

The site uses relative paths, so it can run locally and also work from a project Pages URL such as https://username.github.io/repository/.

Deploy

Publish from the repository root

  1. Create a GitHub repository. Use a public repository for free GitHub Pages hosting.
  2. Push this folder to GitHub. Keep index.html in the repository root.
  3. Enable Pages. In GitHub, open Settings, then Pages, then choose Deploy from a branch.
  4. Select the source. Choose branch main and folder / root.

Static GitHub Pages starter. No backend, no secrets, no build step.
